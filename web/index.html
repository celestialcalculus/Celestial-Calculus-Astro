Settings & methodology

Swiss Ephemeris is the astronomical engine. Sidereal positions use the selected ayanamsa. Vedic analysis defaults to whole-sign houses. Nadi classifications are exposed as data/rules and should not be treated as a universal claim across traditions.

Privacy

No birth data is sent to third-party services by the delivered local server. There is no analytics or telemetry layer.

Platform

The same responsive PWA runs on Windows and Android. GitHub Pages hosts the frontend; Supabase synchronizes private profiles; the Swiss Ephemeris calculation API supplies authoritative astronomical calculations.

Cloud sync

Sign in with the same account on each device. Records are merged by profile ID and latest update timestamp. Local cache remains available when offline.
